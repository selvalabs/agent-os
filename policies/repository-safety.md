# Política — Segurança de repositório

- Verifique estado do Git antes de editar.
- Preserve mudanças não relacionadas.
- Não use `reset --hard`, force push ou limpeza destrutiva sem autorização específica.
- Trabalhe em branch ou worktree quando a tarefa não for trivial.
- Não atualize dependências em massa junto com outra feature.
- Mostre diff e resultados de testes.
- Não silencie testes falhando; explique a origem e o que ficou pendente.
- Prefira pull request para mudanças compartilhadas.
