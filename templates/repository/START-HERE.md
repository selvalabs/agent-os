## Classificação após a tarefa

Antes de criar memória, classifique o resultado:

```text
específico deste projeto
→ atualizar este repositório ou o registro do projeto

estado temporário
→ issue, PR ou HANDOFF

global, transversal ou necessário em sessões futuras
→ Biblioteca de Markdowns

trivial, bruto ou volátil
→ não criar memória durável
```

Não crie um Markdown apenas porque uma tarefa foi concluída.

Quando houver memória global real, registre:

- síntese reutilizável;
- escopo;
- agentes ou ferramentas aplicáveis;
- sessão ou fonte de origem;
- projeto de origem opcional;
- versão e revisão.
