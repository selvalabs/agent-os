# Handoff de agente

Preencha:

- objetivo;
- escopo executado;
- arquivos alterados;
- comandos e testes;
- decisões e motivos;
- riscos e incertezas;
- pendências;
- próxima ação exata;
- links para issue, PR, commit ou deploy.

O próximo agente deve conseguir retomar sem reler toda a conversa.
